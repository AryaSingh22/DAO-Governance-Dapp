# Sepolia Testnet Deployment Checklist

## Prerequisites

- [ ] Infura/Alchemy API key for Sepolia RPC endpoint
- [ ] Private key for deployment account (with Sepolia ETH)
- [ ] Etherscan API key for contract verification
- [ ] Update .env file with the above information

## Environment Setup

- [ ] Install all required dependencies
- [ ] Verify Hardhat configuration
- [ ] Check contract compilation

## Deployment Steps

1. [ ] Deploy GovernanceToken
2. [ ] Deploy TimelockController
3. [ ] Deploy MyGovernor
4. [ ] Deploy Treasury
5. [ ] Deploy MembershipNFT
6. [ ] Setup role permissions
7. [ ] Transfer ownerships
8. [ ] Set guardian roles
9. [ ] Verify contracts on Etherscan

## Post-Deployment

- [ ] Update frontend configuration
- [ ] Test basic functionality
- [ ] Document contract addresses
